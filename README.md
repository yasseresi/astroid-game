# Asteroids

> 📚 **Learning project** — built while following the [boot.dev](https://boot.dev) back-end path. Kept as a record of my progress; not actively maintained.

A small arcade-style asteroids game: move, shoot and split asteroids.

**Stack:** Python, `pygame`, OOP sprite groups

## Run it

```bash
pip install -r requirements.txt && python3 main.py
```
